How it works: the image is decoded to raw pixels and re-encoded via a <canvas>, which discards all embedded metadata segments (EXIF, XMP, IPTC, JUMBF).
Limitations: re-encoding is lossy for JPEG quality settings; PNG → re-encoded PNG. C2PA / Content Credentials manifests are also discarded — a file with no provenance manifest is itself detectable by platforms. This tool does not and cannot defeat AI-content classifiers, which analyze pixels/audio, not just metadata.
