# Metadata Cleaner

A simple privacy-focused tool that removes hidden metadata from files such as images and documents.

## 🚀 Features

- Remove hidden metadata from files
- Protect personal and sensitive information
- Simple and easy-to-use interface
- Supports common file formats
- Privacy-focused processing

## 🔒 Why Metadata Cleaning?

Files can contain hidden information such as:

- Device and camera details
- GPS/location information
- Creation and modification dates
- Author information
- Software details

Metadata Cleaner helps remove this information before sharing files online.

## 🎯 Use Cases

- Before uploading photos to social media
- Removing location information from images
- Preparing documents for public sharing
- Improving file privacy

## 🔐 Privacy

The goal of this project is to minimize unnecessary metadata exposure. Always verify the cleaned file before sharing sensitive information.
